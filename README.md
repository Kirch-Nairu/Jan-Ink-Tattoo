# Jan Ink Tattoo

Official web portfolio and booking experience for **Jan Ink Tattoo**, featuring tattoo work by **John Salceda**.

## Product direction

The site is being built as a dark editorial tattoo portfolio rather than a generic shop template. Photography is the primary visual language, with restrained vermilion accents, warm bone typography, subtle print-grain texture, and motion that supports the artwork instead of competing with it.

## V1 goals

- Curated tattoo portfolio with category filtering and project lightboxes
- Dynamic rotating hero using selected work
- Artist section using John’s working photo
- Mobile-first Facebook booking/inquiry flow
- Interactive inquiry builder that formats a client brief
- Tattoo process, FAQ, and contact sections
- SEO and social metadata
- Responsive motion with reduced-motion support
- Vercel-ready Next.js deployment
